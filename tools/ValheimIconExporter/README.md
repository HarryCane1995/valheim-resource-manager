# ValheimIconExporter

Локальный инструмент только для чтения. Он получает каталог предметов и настоящие пиктограммы из собственной установленной копии Valheim. Игра, сохранения и исходные игровые ассеты не изменяются; DLL игры читаются для восстановления структуры сериализованных данных, игровой код не запускается.

## Установка и запуск в Windows

Требуется Python 3.11 или новее. Выполняйте команды из корня проекта; установка зависимостей нужна один раз:

```powershell
py -m venv .runtime/unity-export-env
.runtime/unity-export-env/Scripts/python.exe -m pip install -r tools/ValheimIconExporter/requirements.txt
.runtime/unity-export-env/Scripts/python.exe tools/ValheimIconExporter/export_items.py --game "D:/SteamLibrary/steamapps/common/Valheim" --game-version "1.0.20"
```

В `--game` укажите фактическую папку, содержащую `valheim_Data`. Значение `--game-version` должно быть независимо прочитано из установленной игры. Пример версии в команде не подтверждает версию вашей установки. Версия Unity не является версией Valheim. Если версия игры неизвестна, экспортёр оставляет `UNKNOWN`.

По умолчанию результат сохраняется в `localdata/` корня проекта. Эта папка исключена из Git. Другое место можно задать через `--output "D:/Private/ValheimResourceData"`; вывод внутри игровой установки запрещён. Backend должен использовать ту же папку локальных данных, чтобы видеть каталог и PNG.

Создаются:

- `localdata/registry/items.json` — стабильные `prefab:<имя>` ID, prefab, signed hash, RU/EN названия, размер стопки, метаданные ItemDrop, ключи и варианты пиктограмм.
- `localdata/registry/extraction-report.json` — найденные определения, пропуски, конфликтующие переводы, ошибки ссылок и экспорта изображений.
- `localdata/icons/<sha256>.png` — локальные игровые пиктограммы с прозрачностью; повторные изображения имеют общий ключ содержимого.

## Источник и ограничения

Инструмент читает SoftRef manifest и UnityFS bundles, восстанавливает сериализованный `ObjectDB.m_items` и `ItemDrop.m_itemData.m_shared`. Имена RU/EN берутся из локальных CSV-таблиц локализации. Конфликтующие непустые переводы отмечаются в диагностике; пустые обновления не стирают имеющийся перевод.

Sprite восстанавливается через UnityPy, включая ссылки на текстуры/атласы. Область Sprite и `textureRectOffset` размещаются на исходном прозрачном холсте без растягивания изображения. Доступные варианты сохраняются отдельно в метаданных предмета. Отсутствующий Sprite не заменяется придуманной картинкой.

Это **статический каталог установленной игры**: `scope: installed-assets`, `runtimeVerified: false`. Процент сопоставления относится к найденному сериализованному ObjectDB. Он не доказывает полноту текущего ObjectDB запущенной игры, предметов установленных модов или содержимого мира. Для этого нужен runtime-экспорт BepInEx-плагина и отдельная сверка покрытия. Неизвестные и неразрешённые записи остаются в отчёте.

Для загрузки зависимых bundles и декодирования текстур может потребоваться примерно **2–4 ГБ RAM**, иногда больше в зависимости от версии игры и размера ассетов. Не запускайте несколько экспортов одновременно. Используются зафиксированные версии библиотек из `requirements.txt`; проверяемый формат установки — UnityFS/Unity 6000. Изменения версии Unity, типов сериализации, compression или структуры manifest могут потребовать обновления инструмента. Неподдерживаемые и повреждённые форматы должны завершаться явной ошибкой либо отмечаться в диагностике, без угадывания определений или иконок.

Экспортёр не перезапускает Valheim и не внедряется в текущую игровую сессию. Чтение ассетов может создать дополнительную нагрузку на диск и память.

## Права на изображения

Полученные PNG и данные ассетов предназначены для локального использования. Наличие установленной игры и возможность извлечения не дают разрешения на распространение изображений. **Не добавляйте игровые PNG, bundles, DLL, сохранения или созданный локальный каталог в публичный репозиторий.** В Git распространяются исходный код экспортёра и синтетические тесты; исключение `localdata/` уже включено в `.gitignore` проекта. При произвольном `--output` самостоятельно держите результат вне публикуемых папок.

## Синтетические тесты

```powershell
.runtime/unity-export-env/Scripts/python.exe -m unittest discover -s tools/ValheimIconExporter -p test_exporter.py -v
```

Тесты не требуют Valheim и не содержат игровых ассетов: известные значения stable hash сверены с реализацией проекта, CSV создаются как текст, изображения состоят из синтетических пикселей, UnityFS headers/directories строятся в памяти и временных файлах. Проверяются UTF-16, конфликт/отсутствие локализации, quoted multiline CSV, прозрачность/смещения/пропорции Sprite, alignment, metadata в конце bundle, LZ4 и отказ на повреждённых/неподдерживаемых заголовках. Это тесты алгоритмов экспортёра, а не подтверждение интеграции с запущенной игрой.
